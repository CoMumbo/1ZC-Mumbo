# Analyze a News Article

**Type:** Summative Lab
**Status:** Complete

## Objective

Build a Python script that analyzes a news article and reports:

- Occurrences of a specific word
- The most common word
- Average word length (punctuation excluded)
- Number of paragraphs
- Number of sentences

## Files

| File | Purpose |
|---|---|
| `problem-statement.txt` | Assignment brief from Canvas |
| `starter-files/ACME_Apple_Pie_Machine.txt` | Article to analyze |
| `pythonAssessment.py` | Solution script |

## How to run

    cd Analyze-News-Article
    python pythonAssessment.py

## Concepts used

- File I/O
- Regex (`re`)
- `collections.Counter`
- `for` and `while` loops
- Conditionals
